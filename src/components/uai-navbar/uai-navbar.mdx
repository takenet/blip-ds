# Navbar

Agrupa as ações de navegação em um ou mais grupos de conteúdo. Use na horizontal, no topo da página, ou na vertical, como barra lateral.

<Canvas of={UaiNavbarStories.Playground} />

<Controls of={UaiNavbarStories.Playground} />

## Como usar

```jsx
import { UaiNavbar, UaiNavbarContent, BdsButtonIcon, BdsAvatar } from 'blip-ds-react/dist/components';

<UaiNavbar orientation="horizontal" justifyContent="space-between" backgroundColor="surface-paper">
  <UaiNavbarContent>
    <BdsButtonIcon size="short" variant="secondary" icon="home" />
    <BdsButtonIcon size="short" variant="secondary" icon="team" />
  </UaiNavbarContent>
  <UaiNavbarContent>
    <BdsAvatar name="Dwight Schrute" size="small" />
  </UaiNavbarContent>
</UaiNavbar>;
```

- Envolva cada conjunto de itens de navegação em um `UaiNavbarContent`. Os grupos seguem a orientação do Navbar e centralizam os itens.
- Carregue os tokens UAI e defina o tema em um elemento acima: envolva a página em um `UaiThemeProvider`, ou carregue `blip-tokens/build/css/uai.css` e use `data-uai-theme="light"` ou `"dark"`. Sem tema, o Navbar usa os valores do tema claro.
- Fora do React, use os custom elements `<uai-navbar>` e `<uai-navbar-content>`, com atributos em kebab-case (`justify-content`, `background-color`).

## API

| Prop React | Padrão | Descrição |
| --- | --- | --- |
| `orientation` | `vertical` | Direção do eixo principal. `horizontal` coloca os grupos em linha; `vertical`, em coluna. |
| `justifyContent` | `space-between` | Distribuição dos grupos no eixo principal: `flex-start`, `center`, `flex-end`, `space-between`, `space-around` ou `space-evenly`. |
| `backgroundColor` | `surface-paper` | Token de superfície UAI: `surface-background`, `surface-contrast`, `surface-inverse`, `surface-muted` ou `surface-paper`. |
| `dataTest` | `null` | Seletor opcional para testes, aplicado no elemento interno do navbar. |

## Layout

- Os itens de um `UaiNavbarContent` ficam a 8px uns dos outros (`spacing-xs`).
- Os grupos ficam a 24px uns dos outros (`spacing-lg`).
- Na horizontal, o Navbar ocupa toda a largura e tem 16px de padding vertical (`spacing-md`).
- Na vertical, o Navbar tem a largura do conteúdo, ocupa toda a altura e tem 16px de padding em cada lado (`spacing-md`).

## Acessibilidade

- Toda ação só com ícone precisa de nome acessível, como `aria-label` no botão.
- Mantenha a ordem dos grupos igual à ordem de leitura da página: navegação principal primeiro, ações da conta por último.

## Tokens

| Parte | Tokens |
| --- | --- |
| Fundo | `surface-background`, `surface-contrast`, `surface-inverse`, `surface-muted`, `surface-paper` |
| Espaçamento | `spacing-xs`, `spacing-md`, `spacing-lg` |

## Migração do `bds-navbar`

O `BdsNavbar` está deprecado. Use o `UaiNavbar` com grupos `UaiNavbarContent`.

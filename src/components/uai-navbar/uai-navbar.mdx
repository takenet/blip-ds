# Navbar

`Navbar` groups navigation actions into one or more content groups. Use it horizontally at the top of a page or vertically as a side rail.

<Controls of={UaiNavbarStories.Playground} />

## Usage

```jsx
import { UaiNavbar, UaiNavbarContent, BdsButtonIcon, BdsAvatar } from 'blip-ds-react/dist/components';

<UaiNavbar orientation="horizontal" justifyContent="space-between" backgroundColor="surface-paper">
  <UaiNavbarContent>
    <BdsButtonIcon size="short" variant="secondary" icon="home" />
    <BdsButtonIcon size="short" variant="secondary" icon="team" />
  </UaiNavbarContent>
  <UaiNavbarContent>
    <BdsAvatar name="Dwight Schrute" size="small" />
  </UaiNavbarContent>
</UaiNavbar>;
```

- Wrap each set of navigation items in `UaiNavbarContent`. Content groups follow the Navbar orientation and center their items.
- Load the UAI tokens and set the theme on an ancestor: wrap the page in `UaiThemeProvider`, or load `blip-tokens/build/css/uai.css` and set `data-uai-theme="light"` or `"dark"`. Without a theme, the Navbar uses the light surface values.
- Outside React, use the `<uai-navbar>` and `<uai-navbar-content>` custom elements, with kebab-case attributes (`justify-content`, `background-color`).

## API

| React prop | Default | Description |
| --- | --- | --- |
| `orientation` | `vertical` | Main axis direction. `horizontal` lays groups out in a row; `vertical` lays them out in a column. |
| `justifyContent` | `space-between` | Distribution of content groups along the main axis: `flex-start`, `center`, `flex-end`, `space-between`, `space-around` or `space-evenly`. |
| `backgroundColor` | `surface-paper` | UAI surface token: `surface-background`, `surface-contrast`, `surface-inverse`, `surface-muted` or `surface-paper`. |
| `dataTest` | `null` | Optional selector for tests, set on the inner navbar element. |

## Layout

- Items within a `UaiNavbarContent` group are 8px apart (`spacing-xs`).
- Content groups are 24px apart (`spacing-lg`).
- A horizontal Navbar fills the available width and has 16px vertical padding (`spacing-md`).
- A vertical Navbar fits its content width, fills the available height and has 16px padding on each side (`spacing-md`).

## Accessibility

- Give every icon-only action an accessible name, such as `aria-label` on the button.
- Keep the order of the groups the same as the reading order of the page: main navigation first, account actions last.

## Tokens

| Part | Tokens |
| --- | --- |
| Background | `surface-background`, `surface-contrast`, `surface-inverse`, `surface-muted`, `surface-paper` |
| Spacing | `spacing-xs`, `spacing-md`, `spacing-lg` |

## Migration from `bds-navbar`

`BdsNavbar` is deprecated. Use `UaiNavbar` with `UaiNavbarContent` groups.

# Avatar

Representa uma pessoa por imagem ou pelas iniciais do nome. Use em listas, cabeçalhos de perfil, navegação e grupos de participantes. Com `upload` ou `openUpload`, vira um botão para trocar a foto. Não use para ícones de ação nem para logos de marca.

## Visão geral

No React, importe `UaiAvatar` de `blip-ds-react/dist/components` e passe `name` e, quando houver, `thumbnail`. As iniciais vêm do nome: a primeira letra do primeiro nome e a do último, em maiúsculas. Envolva a tela em um `UaiThemeProvider` e carregue a fonte **Figtree** e o CSS dos ícones UAI uma vez na aplicação (`import 'blip-tokens/uai-icons/css'`). Fora do React, use o custom element `uai-avatar`, com as propriedades em kebab-case (`open-upload`, `data-test`) e os eventos `uaiClickAvatar` e `uaiImageUpload`.

## Como usar

Cabeçalho de perfil com a foto da pessoa. Com `openUpload`, ativar o avatar abre o seletor de imagem; `onUaiImageUpload` recebe a imagem como data URL e atualiza o estado. O código abaixo pode ser copiado como ponto de partida.

<Canvas of={UaiAvatarStories.Usage} sourceState="shown" />

- Passe sempre o nome completo em `name`: ele gera as iniciais e é o nome acessível. `name="ana maria silva"` mostra `AS`.
- `thumbnail` recebe a URL da foto. Se a imagem não carregar, o avatar mostra as iniciais.
- Use `upload` quando a aplicação cuida da troca de foto (o clique só emite `uaiClickAvatar`) e `openUpload` quando o próprio avatar deve abrir o seletor de imagem.
- Sem `name`, o avatar é decorativo. Use assim só quando o texto ao lado já identifica a pessoa.

## Estados

O avatar mostra, nesta ordem: o contador `+N` com `ellipsis`, a imagem de `thumbnail`, as iniciais do `name` e, sem nome nem imagem, o ícone de usuário. O atributo `hidden` esconde o avatar.

As iniciais usam peso `font-weight/regular` e nunca ultrapassam o círculo, nem com nomes longos no tamanho `micro`.

### Cores

Com `colorLetter` (padrão), o fundo das iniciais vem da primeira letra do nome, como no `bds-avatar`. As demais cores fixam o fundo. `surface` é o fundo neutro do UAI Core.

| `color` | Fundo | Texto |
| --- | --- | --- |
| `colorLetter` (padrão) | pela inicial do nome | `content/primary` |
| `system` e `info` | `feedback/info-subtle` | `content/primary` |
| `success` | `feedback/success-subtle` | `content/primary` |
| `warning` | `feedback/warning-subtle` | `content/primary` |
| `error` | `feedback/error-subtle` | `content/primary` |
| `surface` | `surface/muted` | `content/secondary` |

### Eventos

| React | Custom element | Quando | `detail` |
| --- | --- | --- | --- |
| `onUaiClickAvatar` | `uaiClickAvatar` | A pessoa clica no avatar ou o ativa pelo teclado | `PointerEvent` do clique |
| `onUaiImageUpload` | `uaiImageUpload` | Com `openUpload`, a pessoa escolhe uma imagem | Data URL da imagem |

### Movimento

A camada de upload aparece com `duration/fast` e `easing/standard`. Com `prefers-reduced-motion: reduce`, aparece sem transição (`test/uai-avatar.e2e.ts`).

## Acessibilidade

- O avatar estático tem `role="img"` com o `name` como rótulo e não recebe foco.
- Com `upload` ou `openUpload`, o avatar é um botão: recebe foco com Tab e é ativado com Enter ou Espaço. O foco aparece como anel (`uai-focus-visible`) e mostra o ícone de upload.
- Sem `name`, o avatar é decorativo e não é anunciado. Use só quando o texto ao lado já identifica a pessoa. Com `upload` ou `openUpload` e sem `name`, o botão se chama apenas "Avatar": passe o `name`.
- No contador, passe em `name` o que o `+N` representa, como "Mais 5 pessoas".
- A cor do fundo é só visual: as iniciais e o nome acessível identificam a pessoa.

## Migração do `bds-avatar`

Props, valores e o payload dos eventos têm os mesmos nomes do `BdsAvatar`. Troque só a tag e os eventos:

| `BdsAvatar` | `UaiAvatar` |
| --- | --- |
| Tag `bds-avatar` | Tag `uai-avatar` |
| `onBdsClickAvatar` (`bdsClickAvatar`) | `onUaiClickAvatar` (`uaiClickAvatar`), com o mesmo `PointerEvent` |
| `onBdsImageUpload` (`bdsImageUpload`) | `onUaiImageUpload` (`uaiImageUpload`), com a mesma data URL |
| Avatar estático recebe foco | Só recebe foco com `upload` ou `openUpload` |

## Migração da API anterior do `uai-avatar`

| Antes | Agora |
| --- | --- |
| `src` | `thumbnail`. `src` continua aceita como deprecated e avisa |
| `label` | `name`. `label` continua aceita como deprecated e avisa |
| `initials` | Sai: as iniciais vêm do `name`. Sem `name`, `initials` ainda vale, com no máximo 2 caracteres, e avisa |
| Fundo sempre neutro | O padrão é `colorLetter`; use `color="surface"` para manter o fundo neutro |

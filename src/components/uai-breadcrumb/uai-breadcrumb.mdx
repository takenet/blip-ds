# Breadcrumb

## Visão geral

Mostra a posição da página na hierarquia, sem limite de profundidade. Use para voltar aos ancestrais; para título e ações de página, componha com `UaiPageHeader`. Não substitui a navegação principal.

### Como usar

Exemplo React controlado: o consumidor recebe a solicitação de edição e substitui `items` de forma imutável. Os links de demonstração usam fragmentos e mantêm a navegação nativa.

<Canvas of={UaiBreadcrumbStories.Usage} sourceState="shown" />

Envolva a aplicação em `UaiThemeProvider`, carregue **Figtree** e `blip-tokens/uai-icons/css` uma vez. Fora do React:

```html
<uai-theme-provider theme="light">
  <uai-breadcrumb
    items='[{"label":"Início","href":"#inicio"},{"label":"Relatórios"},{"label":"Mensal"}]'
    wrap-items="false"
    editable
    language="pt_BR">
  </uai-breadcrumb>
</uai-theme-provider>
```

Arrays e `labels` também podem ser atribuídos como propriedades do elemento. Use `addEventListener('uaiBreadcrumbItemEdit', handler)` e leia `event.detail`; não use atributos de evento React no HTML.

`items: string | Array<{ label: string; href?: string }>` tem padrão `[]`; `wrapItems` é `true` e `editable` é `false`. O último item é sempre o atual, mesmo com `href`. Não há prop pública `state`.

### Edição opcional

A edição é opcional e fica desligada por padrão (`editable={false}`). Sem `editable`, o breadcrumb só navega e não mostra gatilho de edição. Habilite `editable` apenas quando a aplicação tratar `uaiBreadcrumbItemEdit` e atualizar `items`.

```jsx
<UaiBreadcrumb items={items} />
<UaiBreadcrumb items={items} editable onUaiBreadcrumbItemEdit={handleEdit} />
```

## Estados

<Canvas of={UaiBreadcrumbStories.States} />

Leitura, atual com link e vazio são estados de conteúdo. O gatilho de edição é separado do link: ative-o para testar campo focado, confirmar, cancelar e erro por valor vazio/só espaços. O erro tem mensagem, não apenas cor. Hover e foco são interações reais: passe o ponteiro ou use Tab. Não existe estado desabilitado/carregando do breadcrumb inteiro.

## Comportamento

### Navegação e recolhimento

- Com até três itens, todos aparecem. Acima disso, `wrapItems=true` mostra primeiro, acionador e atual; o painel mantém todos os intermediários na ordem original.
- `wrapItems=false` mostra todos diretamente. Em HTML, `wrap-items` habilita e `wrap-items="false"` desabilita o recolhimento.
- Só itens com `href` são links e têm hover (fundo `overlay-hover`, sem sublinhado). Item sem `href` é texto de contexto, inclusive no painel e no atual, sem hover para não simular clique, e não emite navegação. O atual com `href` continua link nativo.
- Editar é uma ação separada e opcional (`editable`): o rótulo do atual não vira gatilho de edição.
- JSON inválido avisa no console e apresenta o vazio: “Sem itens para exibir no Breadcrumb.” no idioma padrão.
- Mudanças em `items` ou `wrapItems` recalculam o recolhimento e removem painéis obsoletos.

### Edição controlada e eventos

| React | Custom element | Quando | `detail` |
| --- | --- | --- | --- |
| `onUaiBreadcrumbItemClick` | `uaiBreadcrumbItemClick` | Ativar um link visível ou recolhido | `{ label: string; href?: string }` |
| `onUaiBreadcrumbItemEdit` | `uaiBreadcrumbItemEdit` | Confirmar novo rótulo válido | `{ index: number; oldValue: string; value: string }` |

O clique não inclui índice nem evento DOM. É uma notificação, não uma API de roteamento/cancelamento: não use `preventDefault()` nela para implementar SPA. A navegação por `href` permanece nativa.

O editor compõe `UaiInput` e `UaiButton`: recebe foco ao abrir, confirma por Enter ou botão e cancela por Escape ou botão, restaurando o foco ao gatilho quando presente. Blur não salva nem cancela. Enter durante composição IME não confirma; Enter no editor não envia formulário externo nem inclui o rascunho em `FormData`.

A validação usa `trim` apenas para rejeitar vazio: espaços do valor válido são preservados. Confirmar fecha o editor e emite uma vez, sem mutar `items` nem persistir; valor idêntico fecha sem evento. Alterar `items` durante a edição cancela o rascunho. Persistência, feedback de falhas e atualização do estado pertencem ao consumidor.

Essas regras são o contrato dos testes `test/uai-breadcrumb.spec.tsx` (parsing, recolhimento, eventos e edição) e `test/uai-breadcrumb.e2e.ts` (teclado, foco, painel, formulário, IME e temas); execute-os para verificar a implementação.

### Idioma e textos

`language: 'pt_BR' | 'en_US' | 'es_ES'` tem padrão `pt_BR`. `labels?: Partial<UaiBreadcrumbLabels>` sobrescreve apenas as chaves informadas; o restante segue o idioma. Rótulos de `items` não são traduzidos.

| Chave | Finalidade |
| --- | --- |
| `navigation` | Nome acessível da navegação |
| `hiddenItems` | Nome do acionador de intermediários |
| `edit` / `input` | Nome da ação de editar e do campo |
| `confirm` / `cancel` | Nomes das ações de confirmar e cancelar |
| `required` | Mensagem ao confirmar vazio |
| `empty` | Texto do estado vazio |

## Acessibilidade

- Navegação nomeada, lista ordenada e `aria-current="page"` apenas no último item; separadores decorativos não entram no nome acessível.
- Standalone não introduz heading por padrão. `currentHeadingLevel?: 1 | 2 | 3 | 4 | 5 | 6` define `role="heading"` e `aria-level` no texto atual, nunca na navegação inteira. O header secundário repassa `1`.
- Links nativos usam Tab/Enter; botões usam Tab/Enter/Espaço. O painel é lista de links/texto, não menu ARIA; não exige navegação por setas.
- Painel fecha com Escape ou clique fora e restaura foco pelo `UaiOverlay`. Campo e botões têm nomes acessíveis localizáveis.
- Foco visível usa `border/ring`; erro é associado ao campo. Movimento reduzido desativa transições.

### Tokens

| Parte | Tokens / composição |
| --- | --- |
| Texto | `UaiTypo body-base`, `content-primary`, `content-secondary` |
| Espaços e forma | `spacing-xs`, `spacing-md`, `radius-lg` |
| Painel e hover | `surface-paper`, `border-default`, `border-width-default`, `overlay-hover` |
| Foco e movimento | `border-ring`, `duration-fast`, `easing-standard` |
| Editor e ícone | `UaiInput`/`UaiButton` short, `control-height-short`, `UaiIcon` x-small |

Use props públicas; não sobrescreva parts, estilos internos nem acesse Shadow DOM.

## Migração do `bds-breadcrumb`

| Legado | UAI |
| --- | --- |
| `BdsBreadcrumb` / `bds-breadcrumb` | `UaiBreadcrumb` / `uai-breadcrumb` |
| `items`, `wrapItems` | Mesmos formatos, defaults e regra de recolhimento |
| Evento de clique documentado mas não emitido pelo legado | `uaiBreadcrumbItemClick` é a extensão aprovada e emitida |
| Sem edição/localização pública | `editable`, `language`, `labels`, `currentHeadingLevel`, `uaiBreadcrumbItemEdit` aditivos |
| Controles e tipografia legados | Controles UAI e tokens por tema |

Nenhuma prop herdada é removida; não há prop deprecated nesta API. Não há slots ou métodos públicos novos para conduzir edição.

### Design e origem dos textos

Adaptação visual delegada, não paridade comprovada com UAI Core. Não existe alvo UAI Core adequado para este breadcrumb de página; Code Connect fica pendente, sem mapeamento inventado. A fonte Content UAI MCP estava indisponível: os exemplos não alegam validação oficial de conteúdo.

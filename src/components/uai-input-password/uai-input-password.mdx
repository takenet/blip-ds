# Input Password

Campo para inserir senha em uma única linha. Inclui controle acessível de visibilidade, validação nativa, mensagens de feedback e participação em formulários. Para outros dados de texto, use `uai-input`.

## Como usar

```jsx
import { UaiInputPassword, UaiThemeProvider } from 'blip-ds-react/dist/components';
import 'blip-tokens/uai-icons/css';

<UaiThemeProvider theme="light">
  <UaiInputPassword
    label="Senha"
    size="medium"
    name="password"
    autoComplete="new-password"
    required
    minlength={8}
    requiredErrorMessage="Informe a senha."
    minlengthErrorMessage="Use pelo menos 8 caracteres."
    onUaiInputPasswordChange={(event) => setPassword(event.detail.value)}
  />
</UaiThemeProvider>;
```

- Envolva a tela em um `UaiThemeProvider` e carregue a fonte **Figtree** e o CSS dos ícones UAI uma vez na aplicação.
- Use `name` (ou `inputName`) para incluir o valor em formulários. Sem nome, o campo não é enviado.
- `size` aceita `short` ou `medium`; `medium` é o padrão compartilhado com os outros inputs UAI.
- A propriedade `value` não é refletida em um atributo HTML.
- `openEyes` controla a visibilidade. Enquanto mascarada, o campo usa `autocomplete="current-password"`; quando revelada, usa a propriedade `autoComplete`.
- Fora do React, use `<uai-input-password>` com propriedades em kebab-case e eventos como `uaiInputPasswordChange` e `uaiInputPasswordSubmit`.

## Estados

`danger` tem prioridade sobre `success`. Erro e sucesso exibem ícone e mensagem correspondentes. `readonly` mantém a aparência do estado padrão; `disabled` desabilita também o botão de visibilidade e remove o valor do formulário.

## Tamanho

`size="short"` usa `control-height/short` para áreas densas; `size="medium"` usa `control-height/medium` e é o padrão.

<Canvas of={UaiInputPasswordStories.Sizes} />

## Indicador de força

O indicador é opcional e controlado pelo consumidor com `showStrength` e `strengthLevel` (`none`, `low`, `medium` ou `high`). O componente apenas representa o nível recebido: não inspeciona a senha, não calcula força e não garante segurança. O nível `none` deixa os segmentos neutros.

## Comportamento

### Formulário e validação

- O reset do formulário restaura o valor inicial e emite `uaiInputPasswordChange`.
- `required`, `minlength` e `maxlength` usam as restrições nativas de senha. Mensagens personalizadas podem ser definidas com `requiredErrorMessage` e `minlengthErrorMessage`.
- `min` e `max` são mantidos por compatibilidade, mas não aplicam limites numéricos ao campo de senha.
- O componente segue um `fieldset` desabilitado. Campos `disabled` não participam do envio; campos `readonly` participam.
- Enter emite `uaiInputPasswordSubmit`, exceto durante composição de texto (IME). O evento pode ser cancelado para impedir o envio iniciado pelo componente.

### Eventos e métodos

| React | Custom element | Quando | `detail` |
| --- | --- | --- | --- |
| `onUaiInputPasswordChange` | `uaiInputPasswordChange` | O valor muda, digitando ou por código | `{ value }` |
| `onUaiInputPasswordInput` | `uaiInputPasswordInput` | A cada entrada nativa | `InputEvent` |
| `onUaiInputPasswordFocus` / `onUaiInputPasswordBlur` | `uaiInputPasswordFocus` / `uaiInputPasswordBlur` | O campo ganha ou perde o foco | — |
| `onUaiInputPasswordSubmit` | `uaiInputPasswordSubmit` | Enter, exceto durante composição | `{ event, value }` |
| `onUaiKeyDownBackspace` | `uaiKeyDownBackspace` | Backspace ou Delete | `{ event, value }` |

Métodos: `setFocus()`, `removeFocus()`, `getInputElement()`, `isValid()` e `clear()`.

## Acessibilidade e privacidade

- O rótulo visível é um `<label>` associado ao input nativo. Sem rótulo, informe `aria-label`.
- O botão de visibilidade tem nome acessível localizado, `aria-pressed` e tipo `button`, então não envia o formulário.
- Mensagem e indicador são associados ao input por `aria-describedby`; erros definem `aria-invalid`.
- O valor nunca é serializado em atributo HTML; a senha mascarada usa o hint de preenchimento `current-password`.
- O foco é destacado por `:focus-within`, com alternativa de contorno do sistema em modo de alto contraste.

## Migração do `bds-input-password`

| `BdsInputPassword` | `UaiInputPassword` |
| --- | --- |
| `inputName` | Continua aceito; `name` também participa de formulários |
| `openEyes` | Mantido; alterna com botão nativo acessível |
| `value` | Mantido como propriedade, sem reflexão para atributo |
| `min`, `max`, `minlength`, `maxlength` | Comprimento continua validado; limites numéricos não se aplicam a senha |
| Eventos `bds*` | Eventos equivalentes com prefixo `uai` |
| Força calculada internamente | O consumidor informa `showStrength` e `strengthLevel`; o componente não calcula |

Os slots `input-left`, `inside-input-left` e `input-right`, as parts `input-container`, `input` e `input__message` estão disponíveis para composição e estilização.

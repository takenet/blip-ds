# UAI Button

[Design (UAI Core – Components)](https://www.figma.com/design/4H8ECPPE83nfyLcIvhz9I5/UAI-Core---Components?node-id=2050-1815)

O `uai-button` é a versão com a nova UI do `bds-button`. A API é a mesma do `bds-button`, com estas diferenças:

| `bds-button` | `uai-button` |
| --- | --- |
| `bdsClick` | `uaiClick` (o `detail` traz o evento de clique nativo) |
| `bdsLoading` | `loading` |
| `variant` `primary`, `secondary`, `tertiary`, `ghost`, `delete`, `dashed`, `facebook`, `secondary--white` | Não aceitos: use `solid`, `outline` ou `text` com `color` |
| `size` `tall`, `standard` | Não aceitos: use `large` ou `medium` |
| — | `size="compact"` (24px) |
| `bdsLoadingVariant`, `bdsLoadingColor`, `groupIcon` | Aceitos, mas deprecados (aviso no console) |

Valores não aceitos caem no padrão e geram um aviso no console.

## Tema

Os componentes UAI leem os tokens `--uai-*` do `blip-tokens`. Envolva-os em um `uai-theme-provider`:

```html
<uai-theme-provider theme="light">
  <uai-button>Salvar</uai-button>
</uai-theme-provider>
```

A nova UI usa a fonte **Figtree**. Carregue-a na aplicação; sem ela, o botão usa a fonte atual do blip-ds.

## Ícones

Os ícones vêm da fonte `uai-icon` do `blip-tokens` (323 ícones `outline` e 323 `solid`). Use o nome do ícone em `icon`, `iconLeft` ou `iconRight` e escolha o estilo com `iconTheme` (`outline` ou `solid`). O tamanho segue o botão: 16px no `compact`, 20px no `short` e 24px no `medium` e no `large`.

A fonte precisa estar carregada na aplicação, assim como o `uai.css`:

```js
import 'blip-tokens/uai-icons/css';
```

Nomes que não existem na fonte `uai-icon`, e `typeIcon` `logo` ou `emoji`, caem no `bds-icon` antigo com um aviso no console.

Sem texto, o botão fica quadrado. Nesse caso, informe `aria-label`.

## Acessibilidade

- Renderiza um `<button>` nativo: Tab foca, Enter e Space ativam.
- `type="submit"` e `type="reset"` agem sobre o `<form>` que envolve o botão.
- Em `loading`, o botão recebe `aria-busy` e `aria-disabled`.
- Botões só com ícone precisam de `aria-label`.

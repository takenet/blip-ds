# Typo

Texto da interface com a escala tipográfica UAI. Os nomes de `variant` e `bold` correspondem aos estilos de texto do Figma. Os valores usam os tokens `--uai-*` do `blip-tokens`; os novos papéis têm valores de compatibilidade até a instalação da versão do pacote que os publica.

## Como usar

```jsx
import { UaiThemeProvider, UaiTypo } from 'blip-ds-react/dist/components';

<UaiThemeProvider theme="light">
  <UaiTypo variant="heading-lg" bold="semibold" tag="h2">
    Título
  </UaiTypo>
  <UaiTypo variant="body-base">Texto padrão da aplicação.</UaiTypo>
</UaiThemeProvider>;
```

- Envolva a tela em um `UaiThemeProvider`. Ele define os tokens de tipografia e a cor do texto. Sem tema, o texto usa os valores do tema claro e avisa no console.
- Carregue a fonte **Figtree** uma vez na aplicação. Sem ela, o texto usa a fonte atual do blip-ds.
- Fora do React, use o custom element `<uai-typo>`, com as mesmas propriedades em kebab-case (`letter-spacing`).

## Estilos de texto

Cada estilo do Figma é `variant` + `bold`. Por exemplo, `heading/lg/semibold` é `variant="heading-lg" bold="semibold"`.

| `variant` | Tamanho / altura de linha | Pesos no Figma | Uso |
| --- | --- | --- | --- |
| `display` | 40 / 48 | regular, semibold, bold | Hero, landing pages |
| `heading-xl` | 32 / 40 | regular, semibold, bold | Título principal da página |
| `heading-lg` | 24 / 32 | regular, semibold, bold | Seções de conteúdo |
| `heading-md` | 20 / 28 | regular, semibold, bold | Subseções |
| `title-lg` | 18 / 24 | regular, medium, semibold, bold | Títulos de destaque |
| `title-md` | 16 / 24 | regular, medium, semibold, bold | Títulos de card, rótulos fortes, navegação |
| `title-sm` | 14 / 20 | regular, medium, semibold, bold | Títulos compactos |
| `body-lg` | 16 / 24 | regular, medium, semibold, bold | Texto corrido grande |
| `body-base` (padrão) | 14 / 22 | regular, medium, semibold, bold | Texto padrão da aplicação |
| `body-sm` | 12 / 20 | regular, medium, semibold, bold | Texto corrido pequeno |
| `caption` | 12 / 20 | regular, medium, semibold, bold | Apoio, badges |
| `overline` | 10 / 16 | regular, medium, semibold | Tags, uso restrito |

`display` usa a fonte de `font-family-display`; os demais usam `font-family-sans`. `title` continua disponível como alias de compatibilidade para `title-md`. `body-lg` e `body-sm` usam seus próprios tokens semânticos.

O componente aceita qualquer combinação de `variant` e `bold`, mas use as do Figma.

## Semântica

`variant` define a aparência e `tag` define o elemento HTML (`p`, `h1` a `h4` ou `span`). Escolha a tag pela estrutura da página, não pelo tamanho.

<Canvas of={UaiTypoStories.Semantics} />

## Acessibilidade

- Use `tag` de heading (`h1` a `h4`) para títulos, na ordem da página. Leitores de tela navegam por eles.
- `noWrap` corta o texto com reticências; não use em textos que a pessoa precisa ler inteiros.
- A cor padrão é `content-primary`, com contraste para texto nos dois temas.

## Tokens

| Parte | Tokens |
| --- | --- |
| Tamanho e altura de linha | `<papel>-font-size` e `<papel>-line-height` (por exemplo, `title-lg-font-size` ou `body-base-font-size`) |
| Peso | `font-weight-regular`, `font-weight-medium`, `font-weight-semibold`, `font-weight-bold` |
| Fonte | `font-family-sans`, `font-family-display` |
| Espaçamento entre letras | `letter-spacing-normal`, `letter-spacing-expanded` |
| Cor | `content-primary` |
| Margens | `spacing-lg` (títulos), `spacing-md` (parágrafo) |

Componentes que usam o `UaiTypo` por dentro, como o `UaiButton`, mudam a cor com a variável CSS `--uai-typo-color`.

## Migração do `bds-typo`

| `BdsTypo` | `UaiTypo` |
| --- | --- |
| `variant="fs-10"` | `variant="overline"` |
| `variant="fs-12"` | `variant="caption"` ou `variant="body-sm"` |
| `variant="fs-14"` | `variant="body-base"` |
| `variant="fs-16"` (padrão) | `variant="title-md"` ou `variant="body-lg"` |
| `variant="fs-20"` | `variant="heading-md"` |
| `variant="fs-24"` | `variant="heading-lg"` |
| `variant="fs-32"` | `variant="heading-xl"` |
| `variant="fs-40"` | `variant="display"` |
| `bold="semi-bold"` | `bold="semibold"` |
| `bold="extra-bold"` | Sem equivalente: use `bold="bold"` |
| — | `bold="medium"` |
| — | `letterSpacing="expanded"` |
| `lineHeight` | Aceito, mas deprecado e sem efeito (aviso no console). A altura de linha vem do `variant`. |

`variant="title"` permanece como alias compatível de `variant="title-md"`.

Valores não aceitos, inclusive `fs-*`, `semi-bold` e `extra-bold`, caem no padrão (`body-base` e `regular`) e avisam no console.

Outras diferenças:

- O padrão de `variant` passou de `fs-16` para `body-base` (14px).
- As alturas de linha seguem os tokens, em vez de 150% ou 100%.
- `margin` aplica 24px em `display` e headings (antes: 22px ou 20px). `paragraph` continua com 16px.
- A cor do texto é `content-primary`.
- A parte CSS se chama `uai-typo__text`.

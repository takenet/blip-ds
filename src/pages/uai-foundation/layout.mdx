# Layout

Espaços, tamanhos, raios e bordas são iguais nos dois temas. Use os tokens em vez de valores soltos, para as telas manterem o mesmo ritmo dos componentes.

## Spacing

Espaço entre elementos e dentro deles (gap, padding, margem). Os componentes UAI usam principalmente `spacing-xs` (8px), `spacing-sm` (12px), `spacing-md` (16px) e `spacing-lg` (24px).

<DimensionTokens group="spacing" />

## Sizing

Tamanhos fixos de ícones, avatares e indicadores. Os ícones usam `sizing-sm` (16px), `sizing-md` (20px) e `sizing-lg` (24px).

<DimensionTokens group="sizing" />

## Radius

Arredondamento de cantos.

<DimensionTokens group="radius" />

## Border width

Espessura de bordas e do anel de foco.

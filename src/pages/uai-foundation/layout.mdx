# Layout

Espaços, tamanhos, alturas de controle, raios, bordas, larguras e camadas são iguais nos dois temas. Use os tokens em vez de valores soltos, para as telas manterem o mesmo ritmo dos componentes.

## Spacing

Espaço entre elementos e dentro deles (gap, padding, margem). Os componentes UAI usam principalmente `spacing-xs` (8px), `spacing-sm` (12px), `spacing-md` (16px) e `spacing-lg` (24px).

<DimensionTokens group="spacing" />

## Sizing

Tamanhos fixos de ícones, avatares, indicadores e células. Não use em altura de controle (use `control-height`) nem em espaços (use `spacing`). Os ícones usam `sizing-sm` (16px), `sizing-md` (20px) e `sizing-lg` (24px).

<DimensionTokens group="sizing" />

## Control height

Altura de botões, inputs, selects e outros controles. `control-height-medium` é o padrão; na dúvida, use ele.

<DimensionTokens group="control-height" />

## Radius

Arredondamento de cantos.

<DimensionTokens group="radius" />

## Border width

Espessura de bordas e do anel de foco.

<DimensionTokens group="border-width" />

## Opacity

Opacidade só onde o contrato do componente define. Controles de formulário desabilitados usam as cores `content-disabled`, não opacidade.

<DimensionTokens group="opacity" />

## Width

Larguras de superfícies: menu, painel, tooltip, dialog, sidebar, side menu e conteúdo. Campos e menus que acompanham o conteúdo não usam largura fixa: crescem pelo conteúdo, com mínimo e máximo.

<TokenTable category="layout" group="width" />

## Layer

Ordem de empilhamento (`z-index`) entre conteúdo, navegação e header. Dropdowns, tooltips, dialogs, drawers e toasts não usam layers: abrem na top layer do navegador.

<TokenTable category="layout" group="layer" />

## Breakpoint

Larguras de tela para media queries de largura máxima. Media query não lê variável CSS, então os breakpoints existem só em SCSS e JS:

```scss
@use 'blip-tokens/build/scss/uai-layout' as layout;

@media (max-width: layout.$uai-breakpoint-lg) {
  // recolhe o breadcrumb em um menu
}
```

# Elevation

A elevação separa camadas: quanto mais alto o elemento, maior a sombra. Use `elevation-1` para cards, `elevation-2` para menus, popovers e tooltips, `elevation-3` para painéis flutuantes e `elevation-dialog` para modais. Os demais tokens são de componentes específicos, como abas e sidebars.

```css
.card {
  box-shadow: var(--uai-elevation-1);
}
```

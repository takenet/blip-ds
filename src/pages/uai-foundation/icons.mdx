# Icons

Os ícones do UAI vêm de uma fonte de ícones do `blip-tokens`, com 323 ícones `outline` e os mesmos 323 em `solid`. Os nomes são os da biblioteca de ícones do Figma, sem o prefixo do tema: `outline/message/info` é `info`.

Use o componente [`UaiIcon`](?path=/docs/uai-icon--vis%C3%A3o-geral):

```jsx
import { UaiIcon } from 'blip-ds-react/dist/components';
import 'blip-tokens/uai-icons/css';

<UaiIcon name="info" />;
```

- Tamanhos: `x-small` (16px), `small` (20px) e `medium` (24px, padrão).
- Sem `color`, o ícone usa a cor do texto em volta. Com `color`, use um token de `content-*` ou `feedback-*`.
- Use `outline` por padrão e `solid` para estados ativos ou selecionados.

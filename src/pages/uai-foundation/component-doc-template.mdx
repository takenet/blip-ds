````mdx
## Design

[Link do component set no Figma UAI Core.]
````

## Regras do modelo

- **Visão geral:** abre com o que é, quando usar e quando não usar.
- **Playground:** um story `Playground` com `args` e `argTypes` descritos.
- **Estados:** cobre todos os estados do Figma que o componente tem.
- **Comportamento:** cada linha cita o teste que a cobre.
- **Acessibilidade:** nunca vazia, nem para componentes simples.
- **Migração:** vem da linha de base do `bds-*` e do manifesto de migração.
- **JSDoc:** cada prop, evento, método, slot e part público tem JSDoc no formato **o que é · Use · Pair · Avoid**.
